Política de Privacidade

Financeiro Pro — aplicativo pessoal de controle financeiro · vigente desde outubro de 2026

1. O que é o Financeiro Pro

Um aplicativo pessoal, executado no computador do próprio usuário. Não é um serviço comercial, não é oferecido ao público e não tem usuários além do seu autor.

2. Acesso ao Gmail

  • O acesso é somente leitura, pelo escopo https://www.googleapis.com/auth/gmail.readonly. O aplicativo não envia, apaga, move nem altera e-mails.
  • São lidos apenas os e-mails necessários às funções financeiras: confirmações de compra de marketplaces (como Amazon, Mercado Livre e Shopee) e e-mails do banco com o extrato ou a fatura do cartão em anexo. As buscas são restritas a esses remetentes e assuntos; a caixa não é lida por inteiro.
  • De cada e-mail de compra, o aplicativo extrai só o necessário para identificar a compra (por exemplo: produto, data, valor e número do pedido). O corpo integral do e-mail não é armazenado.
  • Anexos financeiros (extrato ou fatura em PDF) são salvos apenas na pasta local do próprio usuário, para a importação que ele já faz manualmente.

3. Onde os dados ficam

  • O processamento é feito principalmente no computador do usuário. Os dados ficam num banco local.
  • O token de autorização do Google (OAuth) fica cifrado localmente, protegido pela conta do usuário no sistema operacional. Ele não é enviado a terceiros.
  • Quando o usuário ativa a sugestão de categoria por IA, apenas um trecho mínimo e sem dados pessoais (por exemplo, o nome do produto) pode ser enviado ao provedor de IA escolhido; nunca o e-mail inteiro.

4. O que nunca é feito

  • Os dados do Gmail não são vendidos, alugados nem compartilhados com terceiros.
  • Os dados não são usados para publicidade nem para criar perfis de anúncios.
  • Nenhuma pessoa além do próprio usuário tem acesso aos dados.

5. Uso limitado (Google API Services)

O uso e a transferência, pelo Financeiro Pro, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Como desconectar

O acesso pode ser encerrado a qualquer momento: pelo botão “desconectar” do próprio aplicativo, que apaga o token local, ou removendo o Financeiro Pro em myaccount.google.com/permissions.

7. Alterações

Mudanças nesta política serão publicadas nesta página, com a data de vigência atualizada.
